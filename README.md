# Sri Lankaプロジェクト

日本とスリランカのチーム向けの日程調整サイトと、架空のゲームシリーズ全5作のカタログです。

- [日程調整を開く](https://tagiri-world-schedule.mikutakane.chatgpt.site/)
- [発売ゲームを開く](https://tagiri-world-schedule.mikutakane.chatgpt.site/games)
- [ソースと画像一式（ZIP）](./source-snapshot.zip)

ZIPには日程調整とゲーム紹介のソースコード、セットアップ手順、5作品のパッケージと各3枚のゲーム画面を収録しています。参加者の画像は公開用のサンプルです。

ゲームの発売日・価格・対応機種は架空の企画設定です。
